# Learning method (evidence-based, AI-era)

| Technique | Why it works | Where used |
|---|---|---|
| Mastery learning (Bloom, 2-sigma) | Fix gaps before advancing; tutoring ≈ +2σ | Hard 90% gate on 4 criteria per module |
| Retrieval practice + spaced repetition (SM-2) | Strongest durable-memory effect | `progress/cards.jsonl`, daily `card due` |
| Interleaving | Better discrimination/transfer | Old cards mixed into each session |
| Prediction-then-measure | Surfaces wrong mental models | Every build: write predicted number first |
| Feynman teach-back | Reveals illusion of competence | `teachback` gate |
| Socratic AI tutoring, hints escalate | Avoids answer-dumping (which hurts learning) | CLAUDE.md protocol |
| Desirable difficulty / transfer tests | Real mastery = novel-problem performance | `transfer` gate |
| Error log | Metacognition; mistakes become cards | each module README |
| Build-to-learn + public artifacts | Portfolio signal in AI economy | `evidence/`, economic artifact |
| Agent-as-teammate fluency | Core skill: directing/evaluating agents | M01-M07, use Claude Code throughout |
| Measurement culture | Systems intuition = numbers | benchmarks logged in evidence/ |

Measurable: scores per criterion (`progress/log.jsonl`), mastery dates, card retention, time-to-mastery, PROGRESS.md, git tags `mastered/*`.
