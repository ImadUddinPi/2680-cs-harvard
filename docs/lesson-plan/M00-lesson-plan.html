M00 Lesson Plan

Seven lessons, each capped at 15 minutes of theory before you touch code. All practice runs from one repo with one command per lab. Every lab ships with tests that tell you when you are right, so you never wait for me to grade your code.

What the research changed

Sources: the course's policy and assignments pages, the JAX Scaling Book inference chapter, PyTorch docs, and the primary resources linked below. Search results for blog posts were thin, so I leaned on primary sources only.

The course assumes 44 terms, and my exam covered about half.It names deadlock, false sharing, NUMA, DMA, RDMA, write-ahead logs, ACID, B-trees, RPC and congestion control, which I did not test. I added all 44 as flashcards (62 cards in the deck with the key numbers). Review them daily; they take 10 minutes.
Every assignment requires Claude Code and an archive of your session files.The AI policy encourages AI use but requires a disclosure note and ownership of every line. Using Claude Code well is a graded skill, so it is part of every lab here.
What the five assignments actually ask for.A1: a web UI that streams an agent's tool calls live. A2: your own agent runtime with retries, schema-checked tools and graceful failures. A3: cut tokens and latency at fixed accuracy, published as a blog post. A4: run a 7 to 8B open model on an inference engine you operate. A5: profile the whole stack and test a written hypothesis. Lab L5 is the skeleton of A2; L4 is the thinking behind A3 to A5.
Verified against a primary source.The Scaling Book gives KV size = 2 x bytes x head_dim x kv_heads x layers x tokens, and tokens/s = batch x bandwidth / (batch x KV + params). My answer key uses the same formulas. It also puts the H100 compute-bound batch at about 280 tokens, which is why batch-1 decode is always memory-bound.
Compute gap for A4 and A5.You are not enrolled, so there is no course GPU cluster. Everything through L5 runs on this laptop (CPU). For A4-style work you will need a rented GPU: AWS G-family instances (new accounts often start with a quota of zero, so request an increase early), or Modal, RunPod or Lambda. I have not checked your AWS quota. Also, the $10 budget alarm is sized for CPU experiments; raise it before any GPU hour.
Windows limits.Windows has no fork() and vLLM does not run natively on it. The copy-on-write demo and later serving work use WSL (Ubuntu is installed). Labs L1 to L5 run natively.
