STEP 1

How the loop works

5 min

A model API call is a stateless function: messages + tool definitions -> one assistant message. That message is either text, or a tool call (name plus JSON input). The API does not execute tools. Your code does.

messages = [{"role": "user", "content": task}]
while steps < max_steps:
    resp = call_model(messages, tools)       # one API call
    messages.append(resp.message)
    if resp.stop_reason != "tool_use":       # text answer: done
        return resp.text
    for call in resp.tool_calls:
        result = run_tool(call.name, call.input)   # your code runs here
        messages.append(tool_result(call.id, result))
  1. Stateless. Every request carries the full messages list. The provider keeps nothing between calls.
  2. Billing follows from that. Call k is billed for every token in messages at that moment: input tokens on call k = sum of everything added in calls 1 to k-1, plus the initial task. Output tokens are billed separately, at a higher rate.
  3. Tool execution, errors, permissions and step limits are all your code. The model only emits JSON that names a tool.
